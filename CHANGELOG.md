# Changelog

All notable changes to **Build 50 (Pure CSS Responsive Landing Page)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-07-29

### Added
- Integrated **Pure CSS Animated Before / After Workflows Clip-Path Slider** in `index.html` and `style.css`.
- Added `#clip-0`, `#clip-25`, `#clip-50`, `#clip-75`, and `#clip-100` state radio inputs.
- Implemented dual-layered comparison canvas:
  - **Before (Legacy Underneath)**: 48-hour manual coding cycle, 18.4% bug rate, 340.5ms hydration.
  - **After (AetherAI Overlay)**: `clip-path` mask revealing 3.5-minute delivery speed, 99.8% precision, and 0.0ms hydration delay.
- Added smooth vertical split line indicator and knob handle transitioning via CSS `cubic-bezier(0.4, 0, 0.2, 1)`.

## [0.1.0] - 2026-07-29

### Added
- Created **AetherAI — Pure CSS Responsive Landing Page** (Build 50).
- Implemented **100% Zero JavaScript** architecture using advanced CSS selectors (`:checked`, `:hover`, `:target`, `:focus-within`, `<details>/<summary>`).
- Implemented **Pure CSS Mobile Menu Toggle** via hidden `#nav-toggle` checkbox.
- Implemented **Pure CSS Dark / Light Theme Switcher** via hidden `#theme-toggle` checkbox and CSS custom properties (`var(--bg-main)`).
- Implemented **Pure CSS Pricing Toggle** (Monthly vs. Annual -20% discount) via hidden radio inputs.
- Implemented **Pure CSS Interactive FAQ Accordion** using native `<details>` and `<summary>` styling.
- Implemented **Pure CSS Modal Overlay Window** triggered via CSS `:target` pseudo-class.
- Implemented **Pure CSS Hero Floating Animations** (`@keyframes floatHero`, `@keyframes pulseGlow`).
- Implemented **Pure CSS Scroll Snap Testimonial Carousel**.
