# Changelog

All notable changes to **Build 50 (Pure CSS Responsive Landing Page)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-29

### Added
- Created **AetherAI — Pure CSS Responsive Landing Page** (Build 50).
- Implemented **100% Zero JavaScript** architecture using advanced CSS selectors (`:checked`, `:hover`, `:target`, `:focus-within`, `<details>/<summary>`).
- Implemented **Pure CSS Mobile Menu Toggle** via hidden `#nav-toggle` checkbox.
- Implemented **Pure CSS Dark / Light Theme Switcher** via hidden `#theme-toggle` checkbox and CSS custom properties (`var(--bg-main)`).
- Implemented **Pure CSS Pricing Toggle** (Monthly vs. Annual -20% discount) via hidden radio inputs.
- Implemented **Pure CSS Interactive FAQ Accordion** using native `<details>` and `<summary>` styling.
- Implemented **Pure CSS Modal Overlay Window** triggered via CSS `:target` pseudo-class.
- Implemented **Pure CSS Keyframe Hero Floating Animations** (`@keyframes floatHero`, `@keyframes pulseGlow`).
- Implemented **Pure CSS Scroll Snap Testimonial Carousel**.
- Added CSS Grid feature card grid (`repeat(auto-fit, minmax(280px, 1fr))`) and Flexbox header/footer/hero layouts.
